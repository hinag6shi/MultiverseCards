# PostgreSQL DB Tool

Интерактивная утилита для просмотра таблиц и удаления строк. Она сама читает схему выбранной базы данных и не привязана к таблицам MultiverseCards.

## Запуск

Из корня проекта:

```sh
python -m pip install -r db-tool/requirements.txt
python db-tool/db_tool.py
```

Подключение берётся из переменных `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`. Если переменные не заданы, значения читаются из `.env` в корне проекта; переменные окружения имеют приоритет. Чтобы открыть другую базу, поменяйте эти значения в `.env` или окружении и запустите утилиту снова.

Утилита перечисляет таблицы, секционированные таблицы, представления и внешние таблицы во всех пользовательских схемах. Представления доступны для просмотра. Для таблицы выберите номер строки — она удалится сразу, без дополнительного подтверждения. Показываются первые 100 строк таблицы.
