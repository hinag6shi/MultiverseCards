## Решения по карточкам

- У карточки нет уровня и опыта. У игрока хранится ссылка на общий шаблон, счётчики усилений и осколки.
- Повторная копия не добавляется в коллекцию; в будущем она будет конвертироваться в осколки.
- Итоговые HP, ST и DF записываются готовыми числами прямо в JSON. Код игры не применяет множитель редкости.
- При подготовке каталога следующая редкость удваивает характеристики: COMMON ×1, UNCOMMON ×2, RARE ×4, EPIC ×8, MYTHIC ×16, LEGENDARY ×32, DIVINE ×64. Если у персонажа нет COMMON-карты, за основу берётся среднее значение COMMON-карт вселенной.
- Параметры правил усиления хранятся отдельно в JSON. Команда `/upgrade` выполняет усиление и списание ресурса атомарно; начисление осколков за повтор доступно сервису наград.
- Платформа проекта — Telegram; перенос на другие платформы не планируется.

## Задача 3 — усиления, осколки и характеристики ✅

**Зачем:** позволить развивать карточки и создать применение золоту и осколкам.

Подзадачи:

- [x] Реализовать `/upgrade <id> <hp|st|df> <gold|shards>` с атомарным списанием ресурса и усилением конкретной карточки. (подзадача 1) (Сергей)
- [x] Настроить прирост HP/ST/DF в процентах от базовой характеристики с округлением; ограничить карточку 21 общим усилением. (подзадача 2) (Олеся)
- [x] Задать настраиваемую формулу золота `C(n) = C0 + a·n + b·n²`, где `n` — общее число уже сделанных усилений на этой карточке. Стартовые коэффициенты предварительные. (подзадача 3) (Олеся)
- [x] Задать фиксированную настраиваемую цену осколков для каждой редкости: COMMON 20, UNCOMMON 17, RARE 14, EPIC 11, MYTHIC 8, LEGENDARY 5, DIVINE 2. (подзадача 4) (Олеся)
- [x] Конвертировать дубликаты карточек в осколки: сервис наград добавляет один осколок за дубликат. Подключение к выдаче карточек появится вместе с PvE/гача. (подзадача 5) (Сергей)
- [x] Использовать атомарные операции репозитория для списания ресурсов, усиления карточки и начисления осколков. (подзадача 6) (Сергей)
- [x] Добавить модульные тесты стоимости, усиления, конвертации дубликатов и граничных случаев. (подзадача 7) (ChatGpt)

Параметры лежат в `src/main/resources/balance/upgrade-rules.json`. Уровень отображается как `+n`, где `n` — сумма усилений HP, ST и DF. Гарант гачи не входит в эту задачу. Нужны интеграционная проверка транзакций с PostgreSQL и ручная приёмка команды; коэффициенты золота предварительные.

## Принцип декомпозиции

Каждая задача должна давать одну крупную связанную возможность. Сначала реализуется логика и её модульные тесты; затем проверяется интеграция с внешней инфраструктурой и проводится ручная приёмка пользовательского сценария.
